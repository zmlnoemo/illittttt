# Self-Study · 学习资源汇总

个人学习过程中收集、记录的资源库。

按主题分三大类：

- **[design/](./design/)** — 设计相关：设计系统、UI/UX、设计语言、组件库
- **[code/](./code/)** — 代码相关：开源项目、框架、工具、库
- **[product/](./product/)** — 产品相关：产品经理技能、PM 框架、PRD 模板

> 本仓库只做**汇总介绍**，不搬运源码。每个资源附原仓库链接，方便点过去看。

---

## 📌 收录原则

- ⭐ 仓库需活跃维护、有一定 star 数或行业认可度
- 📝 每条记录包含：简介、原链接、为什么收录
- 🚫 不收录纯搬运、长期不更新、违反许可证的资源
