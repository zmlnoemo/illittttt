# awesome-design-systems

> 业界最知名的设计系统资源汇总，帮你快速找到可参考、可复用的设计系统。

- **原仓库**：[alexpate/awesome-design-systems](https://github.com/alexpate/awesome-design-systems)
- **简介**：一个持续维护的精选列表，汇集了来自全球大厂和社区的优秀设计系统，涵盖设计 tokens、组件库、文档、使用指南。
- **为什么收录**：当我开始做产品设计、或要给团队搭建设计规范时，最常打开的参考资料之一；目录结构清晰，覆盖广。

## 我的使用建议

- **想学设计系统怎么搭**：先看 Material Design 3 文档（最完整）
- **做 ToB 后台**：参考 Carbon、Ant Design
- **做 C 端产品**：参考 Polaris、Semi Design
- **想看代码实现**：Ant Design、Fluent UI 的源码质量很高
